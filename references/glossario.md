# Glossário — como falar com quem nunca abriu um terminal

Os identificadores continuam em inglês no código. **Ao falar com a pessoa**, use sempre a
coluna do meio. A coluna da direita é proibida em qualquer texto que a pessoa leia:
conversa, Storyboard, mensagem de erro, README de entrega.

| Termo interno | Diga assim | Nunca diga |
|---|---|---|
| `candidate` / id | **trecho** ("o trecho 3 da lista") | candidato, ID, hash |
| `provider` | **de onde vem** (YouTube, Instagram, banco de vídeo) | provedor, provider |
| `project` / `--project` | **pasta do trabalho** | projeto, root |
| `ledger` / `manifest` | **registro da coleta** | ledger, manifest |
| export JSON | **salvar suas decisões num arquivo** | export, JSON, payload |
| `permit` / `evidence` | **anotar de onde veio e o que dá pra usar** | permit, evidência |
| contact sheet | **os quadros do trecho** | contact sheet, sheet |
| `fetch` | **baixar os trechos aprovados** | fetch |
| `verify` | **conferir os arquivos** | verify |
| cooldown / 429 | **pausa obrigatória do site** | cooldown, rate limit, 429 |
| `reference_only` | **só pra ver, não dá pra baixar** | reference_only |
| `segment` | **o pedaço do vídeo** (de X a Y) | segmento, intervalo, range |
| `preview` | **prévia** (o GIF curto do trecho) | preview |
| `rights.status: unknown` | **ainda não conferido** | unknown, a confirmar |
| `rights.status: permitted` | **você anotou que pode** | permitted |
| `rights.status: restricted` | **uso restrito** | restricted |
| `state: pending` (revisão) | **você ainda não disse** | pending |
| `alternative` (decisão) | **pedi outro vídeo** | alternative, outra fonte |

## Três termos que não são sinônimos

- **Aprovar** (no Storyboard ou no chat) = "quero esse trecho". Não é permissão de uso.
- **Poder usar** = a licença da fonte permite publicar. Quem confere é a pessoa, sempre.
- **Baixar** = o arquivo entra em `brolls/clips/`. Só acontece depois das duas coisas acima.
