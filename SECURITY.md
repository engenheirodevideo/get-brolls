# Política de segurança

[English](#security-policy)

## Como reportar uma vulnerabilidade

Envie o relato por e-mail, em privado, para **contato@engenheirodevideo.com.br**, o contato do Engenheiro de Vídeo.

- Não abra uma issue pública com detalhes de exploração.
- Inclua no relato: a descrição do problema, os passos para reproduzir, o impacto que você identificou, a versão do GET B-ROLLS e o sistema operacional em que o problema aparece.
- Não inclua credenciais, chaves ou dados pessoais de terceiros.

## Versões com suporte

Somente a versão mais recente publicada da ferramenta tem suporte.

## Escopo

Este repositório não contém código-fonte. Ele é a página pública do produto (LICENSE, README e imagens). O produto é distribuído aos membros a partir de um repositório privado. Relatos sobre a ferramenta são bem-vindos pelo mesmo canal de e-mail.

## Security policy

## How to report a vulnerability

Send the report privately by e-mail to **contato@engenheirodevideo.com.br**, the Engenheiro de Vídeo contact.

- Do not open a public issue with exploit details.
- Include in the report: a description of the problem, steps to reproduce it, the impact you identified, the GET B-ROLLS version and the operating system where it appears.
- Do not include credentials, keys or third-party personal data.

## Supported versions

Only the latest published version of the tool is supported.

## Scope

This repository holds no source code. It is the public page of the product (LICENSE, README and images). The product is distributed to members from a private repository. Reports about the tool are welcome through the same e-mail channel.
