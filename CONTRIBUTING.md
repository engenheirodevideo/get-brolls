# Como contribuir

[English](#contributing)

## O que é este repositório

Este repositório é a página pública do GET B-ROLLS, um produto do Engenheiro de Vídeo, marca da Soma Spacial Studio Ltda. Ele contém apenas o [LICENSE](LICENSE), o [README](README.md) e as imagens usadas nele.

## Contribuições de código

Não aceitamos contribuições de código neste repositório, porque o código-fonte não está aqui. Pull requests com código não serão incorporados.

## Problemas na página ou no README

Se encontrar um erro na página ou no README, abra uma issue neste repositório descrevendo o problema. Para vulnerabilidades, não use issues: siga o [SECURITY.md](SECURITY.md).

## Membros

Se você é membro, use a [Comunidade dos Engenheiros de Vídeo](https://engenheirodevideo.com.br/comunidade/?utm_source=github&utm_medium=readme&utm_campaign=get-brolls) para falar sobre o produto e sugerir mudanças.

## Contributing

## What this repository is

This repository is the public page of GET B-ROLLS, a product of Engenheiro de Vídeo, a brand of Soma Spacial Studio Ltda. It contains only the [LICENSE](LICENSE), the [README](README.en.md) and the images used in it.

## Code contributions

We do not accept code contributions in this repository, because the source code is not here. Pull requests with code will not be merged.

## Problems with the page or the README

If you find an error in the page or the README, open an issue in this repository describing the problem. For vulnerabilities, do not use issues: follow [SECURITY.md](SECURITY.md).

## Members

If you are a member, use the [Engenheiro de Vídeo Community](https://engenheirodevideo.com.br/comunidade/?utm_source=github&utm_medium=readme&utm_campaign=get-brolls) to talk about the product and suggest changes.
